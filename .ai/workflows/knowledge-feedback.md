# Knowledge Feedback Protocol (Human-in-the-Loop)

PoohMa では、実装・テスト・レビュー・CI修正で得られた貴重な知見を失わず、AIと開発チームが継続的に成長できるように、**「Knowledge Feedback Loop（知識還元ループ）」** を運用しています。

AI Agent が独断で知識ファイルを勝手に書き換えることはせず、**「知見の判定 → 草案の提示 → ユーザーの合意 → ファイル反映」** という **Human-in-the-Loop（人間とAIの協調）** を必須とします。

---

## 1. 知見還元の判断マトリクス

発生した問題や調査結果が、`.ai/pitfalls/` 等へ還元すべきものかを以下の基準で判定します。

| 事象・発生パターン | 還元判定 | 理由・対応 |
| :--- | :---: | :--- |
| **単なるタイポ、軽微な構文ミス、一時的な環境変数未設定** | ❌ **不要** | 再発防止知識としての普遍性が低く、トークン浪費になるためPR/コミットで完結。 |
| **一時的な外部API障害、ネットワークタイムアウト** | ❌ **不要** | 一過性のインフラ事象。 |
| **アーキテクチャ・設計上の制約に起因するハマりどころ** | ⭕ **必須** | 他のコンポーネントや将来の実装でも同様の誤解が生じやすいため。 |
| **E2EE / 暗号処理における鍵導出やブラウザCrypto APIの罠** | ⭕ **必須** | セキュリティ・暗号不変条件に直結するため。 |
| **Convex / RLS / customBuilders のクエリ・トランザクション挙動** | ⭕ **必須** | バックエンド実装の一貫性を維持するため。 |
| **Playwright / Vitest のセレクタ競合や非同期タイミング問題** | ⭕ **必須** | テストのフレイキー化を防ぐため。 |
| **外部AI（CodeRabbit等）の誤指摘却下パターン** | ⭕ **必須** | 次回のPRレビューで同じ不毛な議論を繰り返さないため。 |
| **PowerShell / Windows 環境固有のエスケープや文字化け問題** | ⭕ **必須** | CLI実行時の破壊事故を防ぐため。 |

## 2. Pitfall 統一フォーマット

`.ai/pitfalls/` に追記・新規作成する際は、以下の 6 要素フォーマットに統一してください。

```markdown
### N. [タイトル: 何についての落とし穴か]

- **問題 (Problem)**:
  何が起きたか（エラー現象、CI失敗、予期しない動作）。
- **原因 (Root Cause)**:
  なぜ起きたか（根本的な仕様制約、非同期タイミング、暗号アルゴリズムの前提）。
- **誤ったアプローチ (Anti-Pattern)**:
  安易にやってしまいがちな誤った対処（「念のため二重にする」「生エラーを画面に出す」など）。
- **正しいアプローチ (Correct Pattern)**:
  PoohMa の設計思想・不変条件に合致した恒久対処。
- **再発防止 (Prevention)**:
  今後同様の作業をする際に何を確認・実行すべきか（チェックコマンドや不変条件）。
- **関連実装 (Related Code References)**:
  実在するファイルパス（例: `apps/web/src/lib/crypto.ts`, `apps/web/convex/customBuilders.ts` 等）。
```

> **注意**: 「関連実装」に記載するファイルパスは必ず実在するパスを記述してください。`pnpm check:knowledge` で参照の整合性が機械検証されます。

---

## 3. Human-in-the-Loop 運用プロトコル

AI Agent は、作業中に上記「還元必須」の知見を発見した場合、以下のフローで還元を実行します：

```text
問題発生・解決
  ↓
知見の普遍性を判定（還元マトリクス確認）
  ↓
AIが Pitfall 草案を作成し、ユーザーに提示
  「💡 新しい知見の提案:
    今回の〇〇について、以下の内容で .ai/pitfalls/xxx.md への追加を提案します。
    ご確認いただけますか？
    [草案内容]」
  ↓
ユーザーの確認・合意（「ok」「修正指示」等）
  ↓
合意後に .ai/pitfalls/xxx.md へ反映
  ↓
pnpm check:knowledge で参照切れがないことを確認
  ↓
コードと同時にコミット
```

AI Agent がユーザーの事前の確認なしに `.ai/` の内容を独断で新規追加・大幅改変することは固く禁じます。
